## False positives

- **mock-server**: Unauthenticated endpoint: GET /api/health (`/api/health`, confirmed). A health check is meant to be public and returns only {status: ok}. Reported because the OpenAPI spec declares no security scheme.
- **injection-lab**: Fuzz: Response contains unescaped <script> tag (XSS) (`/api/generate`, potential). The response is text/plain, so a <script> string in it does not execute. The fuzzer's XSS heuristic does not check Content-Type, which is why it labels this potential.

## False negatives

- **repo-fixture**: `unprefixed-signing-key` (`src/webhooks.js`). High-entropy value with no provider prefix and a variable name outside the generic patterns. Pattern-based detection is expected to miss this; it is kept to keep the recall figure honest.

## Limits of these numbers

The bundled targets are small and were written by the same people who wrote the scanner, so they measure regressions and the false-positive controls, not real-world accuracy. Scores against third-party targets such as OWASP Juice Shop or crAPI are only meaningful once their findings are labelled; see [README.md](README.md#optional-targets).
