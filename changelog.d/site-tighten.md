section: Site

- **A live security check on penthera.org.** Type an address and get a score,
  the failures first with evidence, a fix and a command to verify it, and a
  prompt for your coding agent built from the checks you pick. Anyone can run
  the passive report on any public site: headers, TLS, cookies, secrets and
  vulnerable libraries in the page and its scripts, SRI, mixed content, SPF,
  DMARC, CAA and security.txt, using only what a browser loads. Owners who
  prove the domain with a DNS record or a file also get the CLI's
  payload-free scan for exposed files, debug pages and API specs. Nothing is
  stored. The API is described in `/openapi.json`.
- **A clearer page.** Eight chapters, each answering one question once, and
  an About chapter. The drag-and-drop file check is gone. Brushed-metal
  plates lit by one light that follows the pointer, gradient numbers, a lit
  blue band and soft gradient buttons.
- **Ready for agents.** The homepage and 404s answer `Accept: text/markdown`,
  the page carries JSON-LD, and llms.txt says when to use Penthera.
