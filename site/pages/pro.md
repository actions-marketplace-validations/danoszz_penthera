# Penthera Pro

> In validation. Nothing to buy yet.

A security partner for software built with agents. The agent does the checks. A person does the judgment. Security across the stack: for the developer, the designer and the founder. Pro takes on part of what an in-house security expert does, and spreads it across everyone who ships.

{{CTA}}

## What it is

1. **The agent is free.** Penthera stays MIT and runs on your machine. Every check Pro uses is in the free tool first. Your code is never uploaded.
2. **Pro adds a person.** We set it up with you, run it on a schedule and read what it finds. A few calls a year, when it matters.
3. **Assessments, when you need one.** A closer look at one app, one release or one question, with the evidence. Quoted on its own.

$100–300 a month per team, while we test. Assessments are quoted separately.

Rather run it yourself? `npx penthera@{{VERSION}} init --yes` sets up the same checks in your own CI, free.

**In research:** checks your agents can call and pay for, one at a time, each with a signed verdict.

## What it is not

- **Not a whole security team.** It takes on part of what an in-house security expert does, not all of it.
- **Not a certification and not a pentest.** It shows what was checked and found, with the evidence.
- **Your source code is never uploaded.** Code checks run on your machine or in your own CI.

## How the waitlist works

The button opens an email to Daan, who builds Penthera, at daan@penthera.org. Say who you are and what you'd want: your app checked every week, a person to ask, a custom assessment, or checks your agents can call. Nothing is stored on penthera.org. He replies to every message, and writes again only when there is something to try.
